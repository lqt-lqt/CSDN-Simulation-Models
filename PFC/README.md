# PFC 仿真模型

本目录收录三个 MATLAB/Simulink 模型：

| 文件 | 说明 |
| --- | --- |
| `BoostPFC.slx` | Boost PFC 模型 |
| `PF_L.slx` | PF_L 模型；保留原始文件名 |
| `Valley_FiuPFC.slx` | Valley_FiuPFC 模型；保留原始文件名 |

文件元数据记录的保存版本为 MATLAB/Simulink R2023b。使用时在 MATLAB 中打开所需的 `.slx` 文件。模型所需工具箱、运行参数及仿真结果尚未在本仓库中验证。

这三个文件从本地 `CSDN/PFC` 目录原样复制，未修改模型内容。
